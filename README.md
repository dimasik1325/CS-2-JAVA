## Ключевые обновления версии 9.0 — «Реализм ×1000»

### 1. Арсенал 26 стволов с реальными характеристиками CS2
| Категория | Оружие |
|---|---|
| Пистолеты | Glock-18, USP-S, P250, Five-SeveN, Tec-9, Desert Eagle, Zeus x27 |
| Пистолеты-пулемёты | MAC-10, MP9, UMP-45, P90 |
| Штурмовые винтовки | Galil AR, FAMAS, AK-47, M4A4, M4A1-S, SG 553, AUG |
| Снайперские | AWP, SSG 08 (Scout) |
| Тяжёлое | Nova, XM1014, Negev, M249, RPG-7 |
| Ближний бой | Керамбит |

- Урон, скорострельность (RPM), цена, награда за фраг, бронепробитие, коэффициент дальности (range modifier) и скорость бега взяты из CS2.
- У каждого ствола своя 3D-вьюмодель, силуэт в HUD и магазине, модель в руках ботов, свой звук выстрела и дальнее эхо.
- **AUG / SG 553** — оптический прицел с красной точкой (ПКМ), **SSG 08** — снайперская оптика с точным прыжковым выстрелом.
- Дробовики: дробь летит кольцом (Nova — 9 дробинок, XM1014 — 6), перезарядка по одному патрону.

### 2. Баллистика и урон как в CS2
- **Фиксированные паттерны отдачи** (AK-47 тянет вверх и влево-вправо, M4 мягче); первая пуля стоя точная, разброс растёт от бега, прыжка, присядь — уменьшает.
- **Хитгруппы:** голова ×4, живот ×1.25, грудь ×1, ноги ×0.75. AK-47 убивает в голову с одного выстрела даже в шлеме.
- **Броня и шлем по формуле CS2:** броня поглощает урон с учётом бронепробития оружия, ноги бронёй не защищены; звон шлема при попадании.
- **Падение урона с дистанцией:** `урон × rangeMod^(дист/500 юнитов)`.
- **Пробитие стен по материалу** (до 2 стен): дерево и ящики пробиваются легко, бетон и булыжник — с трудом; урон снижается с толщиной.
- Индикатор хитгруппы, кровь на стенах и полу, свист и щелчки пролетающих пуль, урон от падения с высоты.

### 3. Тактика и мир
- **Выпавшее оружие:** погибшие боты роняют стволы, подбор по `[E]`; рядом с C4 `[E]` по-прежнему обезвреживает бомбу.
- **Боты с личным оружием:** выбирают ствол по команде и сложности, перезаряжаются, стреляют с разбросом и отдачей своего оружия.
- Экран смерти показывает, кто вас убил, из чего и куда попал.
- **Гонка вооружений:** 1 фраг = следующее оружие из всего арсенала.

### 4. Интерфейс
- **Магазин CS2 по категориям** `[B] → [1–6] → [1–7]`: карточки с силуэтом, значком T/CT и шкалами УРОН / ТЕМП / БРОНЯ / БЕГ; `[0]` или `Backspace` — назад.
- **3D-Арсенал** со всеми 26 моделями, полными ТТХ и шкалами мощности, пробития и дальности.
- Новые настройки: кровь, урон от падения, свист пуль. Тест звука перебирает все стволы.

## Ключевые обновления версии 7.0

### 1. Глубокая оптимизация движка `Hyper-Turbo 7.0` (ускорение в 2.5×–3.4×!)
- **Аналитические барицентрические сканлайны $O(1)$ и `16-px Early-Z` отсечение спанов:** растеризатор вычисляет точный интервал `[dxLo..dxHi]` строки без пустых итераций по bbox и пропускает закрытые стенами блоки по 16 пикселей за одну проверку глубины.
- **`Work-Stealing` на всех потоках CPU:** главный рендер-поток участвует в расчётах экранных полос наравне с фоновыми рабочими потоками без простоя на барьерах (удваивает скорость на 2-ядерных системах и линейно масштабируется на 8–16 потоках).
- **`Deferred Skybox Shading`:** градиент неба, объёмные облака и корона солнца вычисляются **только для открытых пикселей (`z == ∞`)** после отрисовки карты, экономя 40%–85% работы шейдера неба.
- **Предвычисление `Digital Vibrance` и `Gamma/Brightness` в Mipmap-уровнях текстур (`0.00 мс` в кадре!):** цветокоррекция и экспозиция запекаются в мипмапы при переключении настройки и не тратят время на каждый пиксель кадра.
- **1-барьерный `L1-Cache Rolling-Row` Post-FX + `AMD CAS` в регистрах + `SWAR` апскейлер:** скользящее окно из 3 строк в L1-кэше процессора без копирования полноэкранного буфера, адаптивная резкость по люминансу без повторного чтения памяти и 16-полосный `SWAR` билинейный апскейлер (в 15× быстрее `Java2D drawImage`).
- **Авто-масштабирование `Dynamic Resolution Auto-FPS` (`60 / 90 / 120 FPS`):** плавно регулирует внутреннее 3D-разрешение в тяжёлых взрывах и дымах, удерживая стабильный FPS, + `0` аллокаций `Font` / `Polygon` / `GradientPaint` в боевом HUD и кэшированная подложка радара.

## Быстрый запуск (Windows 10/11 • Linux • macOS)

1. **На Windows 10 / Windows 11 (x64):** просто скачайте и дважды кликните **`CS-2-JAVA.exe`**!  
   - Весь игровой архив уже встроен внутрь `CS-2-JAVA.exe` (работает как один файл в любой папке, включая русские пути).  
   - Лаунчер запускается без чёрного консольного окна (`WINDOWS_GUI`), с чётким масштабированием `PerMonitorV2 DPI` и фирменной иконкой `CS2 8.0 HD`.  
   - Автоматически находит установленную `Java 11 / 17 / 21 / 25+`, а если на чистой Windows её ещё нет — в 1 клик (без прав администратора) скачивает портативную `OpenJDK 21` (~45 МБ) в `%LOCALAPPDATA%\CS-2-JAVA\jre` и сразу запускает игру.
2. **Альтернативно (Windows / Linux / macOS):** запустите **`run.bat`** или `./run.sh`, либо напрямую:
   ```bash
   java -Xmx1536m -jar CS-2-JAVA.jar
   ```
