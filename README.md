# CS-2 JAVA 2.0 — Тактический 3D-шутер в стиле Counter-Strike 2 на чистой Java

Полноценный трёхмерный шутер от первого лица (FPS) в стилистике легендарной арены **Dust II (Source 2 Edition)**, написанный на стандартном **Java (JDK 11 / 17 / 21 / 25+)** без внешних движков и тяжёлых зависимостей.

Игра работает на собственном высокоскоростном **3D-движке с Z-буфером**, отсечением по ближней плоскости (`Near-Plane Clipping`), текстурами высокого разрешения `128×128` с микрорельефом и Ambient Occlusion, проецируемыми солнечными тенями, объёмными облаками и процедурным синтезатором звука (`javax.sound.sampled`).

## Что нового в версии 2.0

- **Главное меню в стиле CS2 Panorama UI:** интерактивная навигация и быстрая настройка операции на фоне живого пролёта 3D-камеры над ареной Dust II с патрулирующими ботами.
- **Меню Настроек и Настроек графики (с автосохранением в `settings.properties`):**
  - *Графика:* пресеты (`Низкое` / `Среднее` / `Высокое` / `Ультра`), внутреннее разрешение 3D-рендера (`480×270` .. `960×540`), качество солнечных 3D-теней, билинейное сглаживание, объёмные облака и ореол солнца, декали пробоин и вылетающие 3D-гильзы, туман и кино-виньетка, угол обзора `FOV`, лимит `FPS`, время суток (`Полдень` / `Золотой закат` / `Ночная операция`) и полноэкранный режим (`F11`).
  - *Геймплей и мышь:* чувствительность, инверсия оси `Y`, цвет и тип прицела CS2, ведущая рука (`Правая` / `Левая`), цифры урона, сложность ИИ (`Новичок` / `Спецназ` / `Global Elite`).
  - *Аудио:* общая громкость с тестовым выстрелом, звук шагов по песку и звон латунных гильз, телеметрия `FPS`.
- **Экономика CS2 (`$`) и магазин снаряжения (`B`):** зарабатывайте награды за фраги и раунды, сохраняйте оружие при выживании и покупайте 7 видов вооружения и тактические гранаты:
  - **Основное оружие (слот `1`):** `AK-47` ($2700), бесшумная `M4A1-S` с глушителем ($2900), снайперская `AWP` с двукратным оптическим прицелом на `ПКМ` ($4750), полуавтоматический дробовик `XM1014` на 8 картечин ($2000).
  - **Пистолеты (слот `2`):** `Glock-18` ($200) и крупнокалиберный хромированный `Desert Eagle` ($700).
  - **Ближний бой (слот `3`):** `Боевой нож` (быстрый удар `ЛКМ`, мощный выпад `ПКМ`, вращение при осмотре на `F`).
- **Тактические гранаты CS2:**
  - **Осколочная граната HE (`4` или `G`):** рикошетит от стен, взрывается с тряской камеры, осколками и воронкой на песке.
  - **Интерактивная дымовая шашка Smoke (`5` или `Q`):** раскрывает объёмное серое облако дыма, которое реально перекрывает обзор ботам (`Line of Sight`) и временно пробивается выстрелами пуль, как в Counter-Strike 2!
- **Реалистичные детали боя:** физические вылетающие 3D-гильзы со звоном о плитку, следы пуль на стенах, анимация осмотра оружия (`F`), бесшумный шаг (`Shift`), выпадающие трофейные аптечки/патроны и баннеры серий убийств вплоть до **`★ ЭЙС! ★`**.

## Структура проекта

```text
CS-2-JAVA/
├── run.bat               # Автоматическая проверка JDK, сборка и запуск для Windows
├── run.sh                # Сборка и запуск для Linux / macOS
├── src/
│   ├── Main.java         # Точка входа, окно JFrame, полноэкранный режим F11 и self-test
│   ├── Engine.java       # Главное меню, Настройки, Магазин [B], игровой цикл, гранаты и HUD
│   ├── GameSettings.java # Конфигурация графики, геймплея и звука (settings.properties)
│   ├── Renderer3D.java   # 3D-растеризатор: Z-буфер, текстуры 128x128, солнечные тени, дым и небо
│   ├── Map.java          # Архитектура арены Dust II, минарет, разметка плентов A/B и коллизии
│   ├── Player.java       # FPS-контроллер, экономика $, тихий шаг Shift, тряска камеры и K/D
│   ├── Bot.java          # Тактический ИИ (3 уровня сложности, учет дыма CS2 и глушителя)
│   ├── Weapon.java       # 7 видов оружия, оптический зум AWP, дробовик, осмотр F и 3D-модели
│   ├── SoundSystem.java  # Процедурный синтез выстрелов всех пушек, взрывов, шагов и гильз
│   └── Vec3.java         # 3D-математика, AABB, декали, 3D-гильзы, гранаты, облака дыма и трофеи
├── lib/                  # Создается автоматически скриптом запуска
└── bin/                  # Создается автоматически для скомпилированных .class файлов
```

## Быстрый запуск (Windows)

1. Убедитесь, что установлена **JDK 17 или JDK 21+** (например, [Eclipse Adoptium Temurin](https://adoptium.net/temurin/releases/)).
2. Запустите двойным кликом **`run.bat`** (или выполните `.\run.bat` в терминале).
3. Также в архиве доступен готовый исполняемый **`CS-2-JAVA.jar`** (запуск командой `java -jar CS-2-JAVA.jar`).

## Управление

| Клавиша / Мышь | Действие |
| :--- | :--- |
| `W`, `A`, `S`, `D` | Передвижение по арене |
| `Shift` | Тихий шаг (бесшумное движение + повышенная кучность стрельбы) |
| `Space` | Прыжок (каскады ящиков и уступы Dust II) |
| `Ctrl` (или `C`) | Приседание за укрытиями |
| `ЛКМ` | Стрельба / быстрый удар ножом |
| `ПКМ` | Оптический снайперский прицел `AWP` (2.8X / 6.0X) / Прицел ADS / Мощный выпад ножом |
| `B` | Открыть / закрыть **Магазин снаряжения CS2** (покупка мышью или клавишами `1..8`) |
| `R` | Перезарядка оружия |
| `F` | Осмотр 3D-модели оружия в руках (`Inspect`) |
| `1`, `2`, `3` / Колесо | Смена слота оружия (`1` Основное, `2` Пистолет, `3` Нож) |
| `4` (или `G`) | Бросок осколочной гранаты `HE` |
| `5` (или `Q`) | Бросок дымовой гранаты `Smoke` (скрывает от ИИ!) |
| `Tab` | Таблица счёта раундов и живых бойцов |
| `F11` | Переключение оконного / полноэкранного режима |
| `F5` | Быстрый перезапуск матча |
| `ESC` | Меню паузы / Настройки и Настройки графики / Выход в Главное меню |
