## Ключевые обновления версии 6.0

### 1. Мощная многоядерная оптимизация (+51% FPS и выше на многоядерных ПК)
- **16-полосный параллельный растеризатор (`Band-Parallel Lock-Free Rasterizer`)** на постоянном пуле потоков всех ядер процессора с **0 аллокаций в кадре**.
- **`Early-Z` конвейер (стены рендерятся до пола)** — отбрасывает до 70% перекрытых пикселей пола до текстурной выборки.
- **Мгновенный 3D `Frustum Culling` сферами** для зданий, пропсов, цилиндров и ботов вне поля зрения камеры + предвычисленные таблицы `SIN/COS LUT` и общие статические текстуры (мгновенное переключение `F11 Fullscreen`).

### 2. Абсолютно гладкая картинка вообще без пикселей (`Zero-Pixelation Engine`)
- **Нативный рендер `1:1` под размер окна (`1280×720` .. `1920×1080`)** с прямым выводом пиксель-в-пиксель без мыла апскейлинга.
- **16 бесшовных `512×512` материалов с квинтик-шумом Перлина $C^2$, `smoothstep`-фасками, 4 уровнями Mipmap и SWAR Bilinear** + билинейная интерполяция объёмных облаков неба.
- **Двунаправленное 8-шаговое сглаживание краёв `Span FXAA 3.11`**, субпиксельные линии Ву для трассеров и мягкое затенение Гуро (`Gouraud AO`) на архитектуре, цилиндрах, сферах и оружии.

### 3. Полностью новый интерфейс `Panorama Glass UI 6.0`
- **Новое Главное меню:** верхняя стеклянная навигационная панель CS2, щит-герб вашего **воинского звания CS2** с полосой `XP`, живой **3D-Оперативник спецназа SAS CT** с выбранной пушкой и скином на переднем плане, интерактивные карточки 4 карт (`Inferno`, `Dust II`, `Mirage`, `Nuke`) и телеметрия движка.
- **3-колоночный Магазин вооружения `[B]`:** карточки пушек и спецсредств по категориям с горячими клавишами, уроном и балансом.
- **Киберспортивный боевой HUD:** скошенные крылья счёта `CT / TERR`, индикаторы живых бойцов ромбами, биометрическая панель `HP / AP / Рывок [Alt]`, индикатор магазина, цветные плашки 4 гранат и радар со сторонами света и телеметрией ядер CPU.

### 4. Новый игровой контент 6.0
- **Изогнутый нож «Керамбит» (`Karambit`):** 3D-коготь с золотым кольцом под палец и двойным `720°` вращением при осмотре на **`[F]`**!
- **Тактический рывок (`[Alt]`):** стремительный манёвр уклонения с динамическим импульсом `FOV` и шкалой перезарядки в HUD.
- **Точечный Авиаудар Спецназа (`[U]`):** лазерный маяк целеуказания и залп 3 реактивных ракет с неба по позиции врагов (выдаётся за серию из 4 фрагов или покупается в магазине `[B] -> [0]`).
- **Карьера и 10 воинских званий CS2:** от `Silver I` до `★ THE GLOBAL ELITE ★` с автоматическим сохранением `XP`, фрагов и побед.

## Быстрый запуск (Windows / Linux / macOS)

1. Запустите **`run.bat`** (Windows) или `./run.sh` (Linux / macOS), либо напрямую:
   ```bash
   java -Xmx1536m -jar CS-2-JAVA.jar
   ```

## Управление

| Клавиша / Мышь | Действие |
| :--- | :--- |
| `W`, `A`, `S`, `D` / `Shift` / `Ctrl` | Движение / Тихий шаг / Приседание |
| **`Alt`** | **Тактический рывок (Dash) в сторону движения** |
| **`U`** | **Вызов точечного Авиаудара Спецназа (залп 3 ракет с неба)** |
| **`J`** / **`K`** | **Установить 3D Авто-Турель CT** / **Вызвать Босс-Вертолёт (`850 HP`)** |
| `B` (`1`..`0`, `M`) | **3-колоночный Магазин CS2** (`AK-47`, `M4A1-S`, `AWP`, `M249`, `RPG-7`, `Турель + Авиаудар`) |
| `1`, `2`, `3`, `8` (`T`) | Основное оружие, Пистолет, **Керамбит**, **Шокер `Zeus x27`** |
| `4` (`G`), `5` (`Q`), `6` (`V`), `7` (`X`) | Гранаты: `HE`, `Дым` (тушит Молотов), `Флешка`, `Молотов` |
| `F` / `H` / `L` / `Z` / `Y` | **Осмотр оружия (вращение Керамбита!)** / Смена скина / 3D-Фонарик / Радио / Граффити |
| `E` / `R` / `Tab` / `F5` / `F11` / `ESC` | Обезвреживание `C4` / Перезарядка / Счёт / Рестарт / Полный экран / Меню и Настройки |
