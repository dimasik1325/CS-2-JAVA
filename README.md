# CS-2 JAVA — Упрощённый 3D-аналог Counter-Strike 2 на чистой Java

Полноценный трёхмерный тактический шутер от первого лица (FPS) в стилистике арены **Dust II**, написанный на стандартном **Java (JDK 11 / 17 / 21+)** без тяжёлых внешних зависимостей.

Игра использует собственный высокоскоростной программный **3D-рендерер с Z-буфером**, отсечением по ближней плоскости (`Near-Plane Clipping`), перспективно-корректными процедурными текстурами, солнечным освещением и процедурным синтезатором звука на `javax.sound.sampled`.

---

## Возможности игры

- **Честный 3D-вид от первого лица (FPS):** свободный обзор мышью с захватом курсора, движение на `WASD`, прыжки по ящикам (`Space`), приседание за низкими укрытиями (`Ctrl`).
- **Арена в стиле Dust II:** песчаные стены, знаменитые «Двойные двери» на Миду, подъём со ступенями на Плент A, коридор Плента B, деревянные и военные ящики, скользящие 3D-коллизии без прохождения сквозь стены.
- **Арсенал из 3 видов оружия (с 3D-моделями в руках):**
  - `1` — **AK-47** (автоматический огонь при зажатии ЛКМ, `30/90` патронов, ваншот в голову, отдача и вспышка выстрела).
  - `2` — **Glock-18** (точный полуавтоматический пистолет, `20/120` патронов, откат затвора при стрельбе).
  - `3` — **Боевой нож** (ближний бой и ускорение передвижения).
- **Отряд из 5 умных ботов:** патрулируют вейпоинты, обнаруживают игрока по прямой видимости (Raycasting LOS) и звуку выстрелов, маневрируют стрейфами и стреляют в ответ. Раздельные хитбоксы головы (`Headshot`) и корпуса, вспышка попадания, полоса HP и 3D-анимация падения при смерти.
- **Игровой цикл CS2:** система раундов (до 3 побед в матче), радар арены, лента убийств (Killfeed), счётчик `K/D` и точности, таблица счёта (`Tab`), экран победы/поражения и мгновенный рестарт.

## Структура проекта

```text
CS-2-JAVA/
├── run.bat              # Автоматическая проверка JDK, сборка и запуск для Windows
├── run.sh               # Сборка и запуск для Linux / macOS
├── src/
│   ├── Main.java        # Точка входа, создание окна JFrame и запуск движка
│   ├── Engine.java      # Игровой цикл, ввод, захват курсора, стрельба, раунды и HUD
│   ├── Renderer3D.java  # 3D-растеризатор с Z-буфером, текстурами, светом и туманом
│   ├── Map.java         # 3D-арена Dust II, коллизии AABB и трассировка лучей
│   ├── Player.java      # FPS-контроллер игрока, физика прыжков/приседания и K/D
│   ├── Bot.java         # ИИ противников, патруль, стрельба, хитбоксы и анимация смерти
│   ├── Weapon.java      # Оружие (AK-47, Glock-18, Нож), перезарядка и 3D-модели в руках
│   ├── SoundSystem.java # Процедурный синтез звуков выстрелов, шагов и хитмаркера
│   └── Vec3.java        # 3D-математика, AABB-коробки, лучи, трассеры и частицы
├── lib/                 # Создается автоматически скриптом запуска
└── bin/                 # Создается автоматически для скомпилированных .class файлов
```

## Быстрый запуск (Windows)

1. Убедитесь, что установлена **JDK 17 или JDK 21+** (например, [Eclipse Adoptium Temurin](https://adoptium.net/temurin/releases/)). Если JDK не установлена, `run.bat` сам подскажет ссылку и команду установки.
2. Запустите двойным кликом **`run.bat`** (или выполните `.\run.bat` в терминале).
3. Скрипт автоматически проверит `javac`/`java`, подготовит папки `lib/` и `bin/`, скомпилирует все файлы из `src/` и запустит игру.

## Управление

| Клавиша / Мышь | Действие |
| :--- | :--- |
| `W`, `A`, `S`, `D` | Передвижение вперёд, влево, назад, вправо |
| `Мышь` | Обзор камеры на 360° (захват курсора при клике в окно) |
| `ЛКМ` | Стрельба (зажатие для автоогня AK-47) / удар ножом |
| `Space` | Прыжок (запрыгивание на ящики и уступы) |
| `Ctrl` (или `C`) | Приседание (укрытие за низкими блоками + повышение точности) |
| `R` | Перезарядка оружия |
| `1`, `2`, `3` / Колесо мыши | Смена оружия (`1` AK-47, `2` Glock-18, `3` Боевой нож) |
| `Tab` | Таблица счёта и живых противников |
| `F5` (или `Enter` в конце матча) | Полный рестарт матча |
| `[` и `]` (или `-` и `=`) | Уменьшение / увеличение чувствительности мыши |
| `ESC` | Пауза и освобождение курсора мыши |
