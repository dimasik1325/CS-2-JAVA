# CS-2 JAVA 5.0 — Гладкий HD 3D-шутер в стиле Counter-Strike 2 на чистой Java

Полноценный трёхмерный шутер от первого лица (**Smooth HD & Siege Bosses Edition**) с **гладким непиксельным 3D-движком (`Native 720p / Full HD 1080p`, `256×256 Bilinear Mipmap`, `FXAA`, цилиндры и сферы Гуро)**, четырьмя легендарными аренами (**Inferno**, **Dust II**, **Mirage**, **Nuke**), масштабным режимом **«Осада: Волны + Босс-Вертолёт»**, реактивным гранатомётом **RPG-7**, пулемётом **M249** и устанавливаемыми **3D Авто-Турелями спецназа CT**, написанный на стандартном **Java (JDK / JRE 11 / 17 / 21 / 25+)** без внешних движков и тяжёлых библиотек.

---

## Масштабное обновление 5.0 (Smooth HD & Siege Bosses)

### 1. Полностью гладкая непиксельная 3D-графика (`Source 2 Smooth HD Engine`)
- **Нативный HD / Full HD рендер (`1280×720`, `1600×900`, `1920×1080`)** со спановой перспективной коррекцией (`16-px Perspective Span Rasterizer`) — больше никакого пиксельного апскейла из низкого разрешения!
- **16 процедурных HD-текстур `256×256` с 3 уровнями Mipmap и билинейной фильтрацией текселей (`8.8 Fixed-Point Bilinear`)** — даже вплотную у стен, брусчатки, дверей и ящиков поверхности идеально гладкие без квадратных пикселей.
- **Постобработка сглаживания краёв `FXAA` (многопоточная)** — убирает диагональные «лесенки» на крышах, колоннах и оружии.
- **Гладкая криволинейная 3D-геометрия с затенением Гуро (`Gouraud Shading`):** круглые стволы оружия, глушители `M4A1-S`, оптические прицелы `AWP`, сферические шлемы и округлые торсы бойцов, круглые каменные чаши фонтана `Inferno`, градирня и жёлтый реактор `Silo` на `Nuke`, пальмы и кипарисы!

### 2. Масштабный режим «Осада: 5 Волн + Босс-Вертолёт» (`SIEGE_WAVES`)
- **5 нарастающих волн штурма** вместе с вашим отрядом спецназа CT против:
  - **Ударного Боевого Вертолёта-Босса в небе (`850–1150 HP`):** кружит над ареной с вращающимися винтами, кабиной пилота и ракетными блоками, ведёт огонь очередями из 30-мм авиапушки, дымит при критическом уроне и взрывается в небе при уничтожении (можно также вызвать в любой момент клавишей **`K`**!).
  - **Тяжелобронированных Джаггернаутов (`460 HP`)** в чёрно-красной штурмовой броне с пулемётом `M249`.
  - **Снайперов с красным лазерным целеуказателем** и штурмовых отрядов.
- **Воздушные сбросы снабжения (`Supply Drop`) на парашютах:** спускаются с неба с зелёным сигнальным маяком и восстанавливают `100 HP`, `100 AP`, полный боекомплект, гранаты, заряд авто-турели и `+$1200`.

### 3. Четвёртая 3D-карта `Inferno` + Динамическая 3D-Погода + Тяжёлое вооружение
- **Новая карта `Inferno (Старый город)`:** итальянская штукатурка и терракотовые черепичные крыши, брусчатка, круглый каменный **Фонтан с бурлящей водой**, **Колокольня** с золотым колоколом, аркада **Банана** и стройные кипарисы.
- **Динамическая 3D-Погода:** **Ясно**, **Ливень и гроза** (объёмные струи дождя с учётом крыш зданий + вспышки молний) и **Снегопад**.
- **11 видов оружия и гаджетов:**
  - **`RPG-7` (`$4500`):** реактивный гранатомёт с физической 3D-ракетой, огненно-дымовым шлейфом и мощной взрывной волной против Босс-Вертолёта и групп врагов!
  - **`M249 Para` (`$5200`):** тяжёлый пулемёт поддержки с коробом на **100 патронов** (`100 / 200`).
  - **Полевая 3D Авто-Турель Спецназа CT (`J`, `$1200` в магазине `[B] -> [0]`):** устанавливается прямо перед игроком на треноге, вращает сдвоенным стволом на `360°` и автоматически расстреливает врагов и Босс-Вертолёт!

## Быстрый запуск (Windows / Linux / macOS)

1. Запустите двойным кликом **`run.bat`** (Windows) или `./run.sh` (Linux/macOS) — скрипт автоматически скомпилирует исходники или запустит готовый **`CS-2-JAVA.jar`**.
2. Или запустите напрямую: `java -Xmx1536m -jar CS-2-JAVA.jar`.

## Управление

| Клавиша / Мышь | Действие |
| :--- | :--- |
| `W`, `A`, `S`, `D` / `Shift` | Передвижение / Тихий шаг с повышенной точностью |
| `Space` / `Ctrl` (`C`) | Прыжок (или итог раунда после гибели) / Приседание |
| `ЛКМ` / `ПКМ` | Огонь (включая пуск ракеты `RPG-7`) / Оптический прицел `AWP`, ADS, удар ножом |
| `B` (`1`..`0`) | **Магазин снаряжения:** `4` — `M249`, `5` — `RPG-7`, `0` — **Авто-Турель CT (`$1200`)** |
| **`J`** | **Установить 3D Авто-Турель Спецназа CT** перед собой |
| **`K`** | **Вызвать в небо Боевой Вертолёт-Босс (`850 HP`)** |
| `1`, `2`, `3`, `8` (`T`) | Слоты оружия: Основное, Пистолет, Нож, **Электрошокер `Zeus x27`** |
| `Z` / `Y` / `L` | Радиокоманды отряду CT / Цветное 3D-граффити / Тактический 3D-фонарик |
| `4` (`G`), `5` (`Q`), `6` (`V`), `7` (`X`) | Гранаты: `HE`, `Smoke` (тушит огонь!), `Flashbang`, `Molotov` |
| `E` / `R` / `F` / `H` | Разминирование `C4` / Перезарядка / Осмотр оружия / Смена скина |
| `Tab` / `F5` / `F11` / `ESC` | Счёт команд CT vs T / Рестарт / Безрамочный Полный экран / Меню и Настройки |
