# CS-2 JAVA 3.0 — Тактический 3D-шутер в стиле Counter-Strike 2 на чистой Java

Полноценный трёхмерный шутер от первого лица (FPS) в стилистике легендарной арены **Dust II (Source 2 Tactical & Skins Edition)**, написанный на стандартном **Java (JDK 11 / 17 / 21 / 25+)** без внешних движков и тяжёлых зависимостей.

Игра работает на собственном высокоскоростном **3D-движке с Z-буфером**, отсечением по ближней плоскости (`Near-Plane Clipping`), текстурами высокого разрешения `128×128` с микрорельефом и Ambient Occlusion, проецируемыми солнечными тенями, объёмными облаками, направленным 3D-фонариком и процедурным синтезатором звука (`javax.sound.sampled`).

---

## Что нового в версии 3.0

- **3 полноценных игровых режима CS2:**
  - **Операция C4 (Пленты A / B):** один из ботов несёт взрывчатку C4 за спиной, прорывается на точку `A` или `B` и минирует плент. У вас есть `40` секунд, чтобы найти мигающую красную бомбу C4 с ускоряющимся таймером и обезвредить её зажатием клавиши **`E`** (`10` сек без щипцов или `5` сек с **Набором сапёра**)!
  - **Классика: Зачистка:** тактические раунды с экономикой `$` и сохранением оружия.
  - **Бой насмерть (Deathmatch):** бесконечное возрождение игрока и ботов, `$16000` и бесплатный магазин оружия, матч до `25` фрагов.
- **Интерактивная 3D-Оружейная и 5 коллекционных скинов CS2:**
  - Отдельный экран **«Скины оружия (3D Витрина)»** в Главном меню с вращающейся на 360° 3D-моделью каждого из 8 видов оружия и карточкой ТТХ, плюс мгновенное переключение скинов прямо в бою по клавише **`H`**:
    - `Стандарт (Военный)`
    - `Asiimov (Азимов)`
    - `Золотой Градиент (Fade)`
    - `Redline (Карбон)`
    - `Printstream (Кибер-Неон)`
- **Полный пояс из 4 гранат Counter-Strike 2 с физикой взаимодействия:**
  - **Осколочная HE (`4` / `G`):** рикошет от стен, взрыв с воронкой, осколками и тряской экрана.
  - **Дымовая шашка Smoke (`5` / `Q`):** объёмное серое облако дыма, которое блокирует обзор ботам (`LOS`), пробивается пулями и **мгновенно тушит пламя Молотова** при пересечении!
  - **Светошумовая Flashbang (`6` / `V`):** ослепляет ботов в радиусе прямой видимости (они закрывают лицо руками и теряют прицел, над ними загорается `★ ОСЛЕПЛЁН ★`), а для игрока учитывает угол взгляда — отвернитесь от вспышки, чтобы не ослепнуть!
  - **Зажигательный Молотов (`7` / `X`):** при ударе о землю разливает бушующую 3D-зону огня, наносящую периодический урон всем вокруг и отмечаемую на радаре.
- **Новое оружие и тактические гаджеты:**
  - **Пистолет-пулемёт `MP9` ($1250):** скорострельный ПП спецназа (`850 выстр./мин`, повышенная награда `$600` за каждый фраг) — всего **8 видов оружия** (`AK-47`, `M4A1-S`, `AWP`, `XM1014`, `MP9`, `Desert Eagle`, `Glock-18`, `Боевой нож`).
  - **Направленный 3D-фонарик (`L`):** освещает стены, пол, двери и противников в реальном времени с затуханием по глубине Z-буфера (особенно эффектно в режиме **«Ночная операция»**!).
  - **Счётчик `StatTrak™` и карточки фрагов CS2:** цифровой оранжевый индикатор `StatTrak™` на панели оружия и фирменные карточки убийств раунда (`☠ K1..K5` / золотые `HS` за хедшоты) внизу по центру экрана.

## Структура проекта

```text
CS-2-JAVA/
├── CS-2-JAVA.jar         # Готовый самодостаточный исполняемый JAR-файл (Java 11+)
├── run.bat               # Автоматическая проверка JDK/JRE, сборка и запуск для Windows
├── run.sh                # Сборка и запуск для Linux / macOS
├── src/
│   ├── Main.java         # Точка входа, окно JFrame, полноэкранный режим F11 и self-test
│   ├── Engine.java       # Главное меню, 3D-Оружейная, Настройки, Магазин [B], C4, DM и HUD
│   ├── GameSettings.java # Конфигурация режимов, скинов, графики и звука (settings.properties)
│   ├── Renderer3D.java   # 3D-растеризатор: Z-буфер, текстуры 128x128, тени, дым, огонь, фонарик
│   ├── Map.java          # Архитектура арены Dust II, минарет, пленты A/B и коллизии
│   ├── Player.java       # FPS-контроллер, 4 гранаты, щипцы C4, фонарик, ослепление и K/D
│   ├── Bot.java          # Тактический ИИ: минирование C4, ослепление от флешек, респаун DM
│   ├── Weapon.java       # 8 видов оружия, 5 скинов CS2, 3D-витрина, зум AWP и осмотр F
│   ├── SoundSystem.java  # Процедурный синтез MP9, флешек, Молотова, таймера C4 и выстрелов
│   └── Vec3.java         # 3D-математика, AABB, декали, гильзы, 4 типа гранат, огонь и бомба C4
├── lib/                  # Создается автоматически скриптом запуска
└── bin/                  # Создается автоматически для скомпилированных .class файлов
```

## Быстрый запуск (Windows)

1. Запустите двойным кликом **`run.bat`** — скрипт автоматически скомпилирует исходники (если установлен JDK) или мгновенно запустит готовый **`CS-2-JAVA.jar`** (если установлена обычная Java JRE 11/17/21+).
2. Или запустите напрямую командой: `java -jar CS-2-JAVA.jar`.

## Управление

| Клавиша / Мышь | Действие |
| :--- | :--- |
| `W`, `A`, `S`, `D` | Передвижение по арене |
| `Shift` | Тихий шаг (бесшумное движение + повышенная кучность стрельбы) |
| `Space` / `Ctrl` (`C`) | Прыжок / Приседание за укрытиями |
| `ЛКМ` | Стрельба / быстрый удар ножом |
| `ПКМ` | Оптический прицел `AWP` (2.8X / 6.0X) / Прицел ADS / Мощный выпад ножом |
| `E` (удерживать) | **Обезвреживание заложенной бомбы C4** на плентах A и B |
| `B` | Открыть / закрыть **Магазин снаряжения CS2** (клавиши `1..9` или мышь) |
| `R` | Перезарядка оружия |
| `F` / `H` | Осмотр 3D-модели оружия (`Inspect`) / Быстрая смена коллекционного **скина** |
| `L` | Включить / выключить **тактический 3D-фонарик** |
| `1`, `2`, `3` / Колесо | Смена слота оружия (`1` Основное, `2` Пистолет, `3` Нож) |
| `4` (или `G`) | Бросок осколочной гранаты `HE` |
| `5` (или `Q`) | Бросок дымовой шашки `Smoke` (скрывает от ИИ и тушит Молотов!) |
| `6` (или `V`) | Бросок светошумовой гранаты `Flashbang` (ослепляет врагов!) |
| `7` (или `X`) | Бросок зажигательной гранаты `Molotov` (горящая 3D-зона) |
| `Tab` / `F5` / `F11` | Таблица счёта / Быстрый рестарт матча / Полный экран |
| `ESC` | Меню паузы / Настройки и Настройки графики / Выход в Главное меню |
