# CS-2 JAVA 4.0 — Тактический 3D-шутер в стиле Counter-Strike 2 на чистой Java

Полноценный трёхмерный шутер от первого лица (FPS) с тремя легендарными аренами (**Dust II**, **Mirage**, **Nuke**), режимом **«Гонка вооружений»**, отрядом ИИ-союзников спецназа CT, радиокомандами и электрошокером **Zeus x27**, написанный на стандартном **Java (JDK / JRE 11 / 17 / 21 / 25+)** без внешних движков и тяжёлых зависимостей.

Игра работает на собственном высокоскоростном **3D-движке с Z-буфером**, отсечением по ближней плоскости (`Near-Plane Clipping`), 12 процедурными текстурами `128×128` с Ambient Occlusion, проецируемыми солнечными тенями, объёмными облаками, направленным 3D-фонариком и многоканальным процедурным синтезатором звука (`javax.sound.sampled`).

## Что нового в версии 4.0

- **3 легендарные 3D-карты CS2 с уникальной архитектурой и текстурами `128×128`:**
  - **Dust II (Пески):** песчаник, Mid Double Doors, синий контейнер на Long A, Пленты A/B и минарет.
  - **Mirage (Дворец):** марокканская терракотовая штукатурка, сине-золотой мозаичный фриз, Mid Window с перемычкой, Palace-колонны и пальмы за стенами.
  - **Nuke (Ядерный комплекс):** стальные индустриальные панели с предупреждающей жёлто-чёрной разметкой, ангар с потолочными балками, жёлтый реактор `Silo` и градирня АЭС на горизонте.
- **Новый режим «Гонка вооружений» (Arms Race):**
  - 8 уровней оружия (`MP9 → XM1014 → M4A1-S → AK-47 → AWP → Desert Eagle → Zeus x27 → Золотой нож`). Каждые 2 фрага мгновенно повышают уровень без перезагрузки раунда, а удар ножом или разряд `Zeus x27` продвигает уровень сразу! Побеждает тот, кто первым совершит финальное убийство **Золотым ножом**.
- **Отряд ИИ-союзников спецназа CT + Тактические радиокоманды (`Z`):**
  - Вместе с вами в бой выходят боты спецназа в синей броне с голубыми визорами (`▲ CT Альфа`, `CT Браво`...). Они самостоятельно ведут огонь по террористам, отображаются голубыми точками на радаре и **автоматически бегут обезвреживать заложенную бомбу C4**!
  - Клавиша **`Z`** отдаёт голосовые радиоприказы всему отряду: *«За мной! Прикройте!»*, *«Штурмуем Плент A!»*, *«Штурмуем Плент B!»*, *«Держать позицию!»*.
  - Если вы погибли, а союзники живы — вы наблюдаете за их боем или нажимаете **`Пробел`** для мгновенного расчёта исхода раунда.
- **Электрошокер `Zeus x27` (`8` / `T`), Прострелы (Wallbang) и 3D-Граффити (`Y`):**
  - **`Zeus x27`:** 9-е оружие в арсенале (4-й слот инвентаря `8`/`T`) — выпускает зигзагообразную голубую 3D-молнию и нейтрализует противника с одного разряда вблизи, автоматически перезаряжая батарею за `10` секунд.
  - **Прострел укрытий (`Wallbang`):** мощные винтовки (`AWP`, `AK-47`, `M4A1-S`, `Desert Eagle`) пробивают деревянные ящики и двойные двери насквозь с индикацией `[ПРОСТРЕЛ]` в ленте убийств!
  - **Цветные 3D-граффити (`Y`):** нанесение ярких неоновых граффити (корона, прицел, молния) на любые стены, ящики и полы арены со звуком аэрозольного баллончика.
  - **6 коллекционных скинов** (добавлен яркий киберпанк-скин **`Неоновый Зверь / Hyper Beast`**) + двухкомандная таблица счёта `Tab` со звёздами **`★ MVP`**.

## Структура проекта

```text
CS-2-JAVA/
├── CS-2-JAVA.jar         # Готовый самодостаточный исполняемый JAR-файл (Java 11+)
├── run.bat               # Автоматическая проверка JDK/JRE, сборка и запуск для Windows
├── run.sh                # Сборка и запуск для Linux / macOS
├── src/
│   ├── Main.java         # Точка входа, окно JFrame, полноэкранный режим F11 и self-test
│   ├── Engine.java       # Главное меню 4.0, 3D-Оружейная, Гонка вооружений, Радио CT, Wallbang, HUD
│   ├── GameSettings.java # Конфигурация карт, режимов, отряда CT, скинов, графики и звука
│   ├── Renderer3D.java   # 3D-растеризатор: Z-буфер, 12 текстур 128x128, тени, граффити, фонарик
│   ├── Map.java          # 3 арены (Dust II, Mirage, Nuke), спауны команд и рейкаст прострелов
│   ├── Player.java       # FPS-контроллер, 4 слота оружия (Zeus x27), 4 гранаты, прогресс Arms Race
│   ├── Bot.java          # Двухкомандный ИИ (Спецназ CT vs Террористы T), радиоприказы, сапёр C4
│   ├── Weapon.java       # 9 видов оружия (включая Zeus x27), 6 скинов, лестница Arms Race, Wallbang
│   ├── SoundSystem.java  # Процедурный синтез разряда Zeus, баллончика граффити, рации CT и фанфар
│   └── Vec3.java         # 3D-математика, AABB, декали, 3D-граффити, 4 типа гранат, огонь и C4
├── lib/                  # Создается автоматически скриптом запуска
└── bin/                  # Создается автоматически для скомпилированных .class файлов
```

## Быстрый запуск (Windows)

1. Запустите двойным кликом **`run.bat`** — скрипт автоматически скомпилирует исходники (если установлен JDK) или мгновенно запустит готовый **`CS-2-JAVA.jar`** (если установлена обычная Java JRE 11/17/21+).
2. Или запустите напрямую командой: `java -jar CS-2-JAVA.jar`.

## Управление

| Клавиша / Мышь | Действие |
| :--- | :--- |
| `W`, `A`, `S`, `D` | Передвижение по арене |
| `Shift` | Тихий шаг (бесшумное движение + повышенная кучность стрельбы) |
| `Space` / `Ctrl` (`C`) | Прыжок (или ускорение раунда после гибели) / Приседание |
| `ЛКМ` / `ПКМ` | Стрельба / Оптический прицел `AWP` (2.8X / 6.0X), прицел ADS, выпад ножом |
| `1`, `2`, `3`, `8` (`T`) | Слоты оружия: `1` Основное, `2` Пистолет, `3` Нож, **`8` / `T` Электрошокер Zeus x27** |
| `Z` | **Радиокоманда союзникам спецназа CT** (*За мной / Плент A / Плент B / Позиция*) |
| `Y` | **Нанести цветное 3D-граффити** на стену, ящик или пол |
| `E` (удерживать) | **Обезвреживание заложенной бомбы C4** на плентах A и B |
| `B` | Открыть / закрыть **Магазин снаряжения CS2** (клавиши `1..9` или мышь) |
| `R` / `F` / `H` | Перезарядка / Осмотр 3D-оружия (`Inspect`) / Быстрая смена **скина** |
| `L` | Включить / выключить **тактический 3D-фонарик** |
| `4` (`G`), `5` (`Q`), `6` (`V`), `7` (`X`) | Гранаты: `HE` осколочная, `Smoke` дымовая, `Flashbang` светошумовая, `Molotov` |
| `Tab` / `F5` / `F11` / `ESC` | Двухкомандный счёт CT vs T / Быстрый рестарт / Полный экран / Меню паузы |
